Сделка онлайн

Приложение для дистанционных сделок с рассрочкой: проверка личности, договор, подпись кодом из SMS, оплата и личный кабинет клиента. Работает в браузере на компьютере и телефоне.

Запуск на своём компьютере

  1. Установите Node.js версии 22 или новее с сайта nodejs.org (кнопка LTS). Это нужно один раз.
  2. Распакуйте архив в любую папку.
  3. Запустите файл для своей системы:
    • Windows: start.bat двойным щелчком;
    • Mac: start.command. В первый раз щёлкните по нему правой кнопкой и выберите «Открыть»;
    • Linux: ./start.sh в терминале.
  4. Через несколько секунд откроется браузер с адресом http://localhost:3000. Окно с текстом не закрывайте, пока работаете: это сервер.

Установка на сервер для клиентов

Подойдёт любой сервер в России с Ubuntu (Timeweb Cloud, Selectel, Яндекс Облако, REG.RU) от 1 ГБ памяти. Персональные данные клиентов по 152-ФЗ должны храниться в России.

  1. Купите домен или поддомен, например sdelka.ваша-компания.ru, и направьте его A-записью на IP сервера.
  2. Установите Docker на сервер: 
    curl -fsSL https://get.docker.com | sh
  3. Скопируйте папку из архива на сервер и в файле settings.env впишите DOMAIN, свою почту и надёжный пароль в ADMIN_EMAIL и ADMIN_PASSWORD.
  4. Запустите в этой папке: 
    docker compose --env-file settings.env up -d

Через минуту приложение откроется по адресу https://ваш-домен, сертификат HTTPS выпускается сам. Демо-сделок на сервере нет. Данные лежат в томе Docker data, его стоит регулярно копировать.

На телефоне

Клиент открывает ссылку из SMS. Чтобы приложение было на экране телефона с иконкой, в браузере нажмите «Поделиться» → «На экран Домой» (iPhone) или меню → «Добавить на главный экран» (Android).

Отдельные приложения для App Store и Google Play собираются из исходного кода через сервис Expo (EAS). Для этого нужны аккаунты разработчика Apple (99 $ в год) и Google (25 $ один раз).

Первые шаги менеджера

  1. Войдите и откройте «Компания»: впишите реквизиты, они попадут в каждый договор.
  2. В «Сотрудники» добавьте коллег.
  3. Нажмите «Новая сделка», укажите клиента, предмет, сумму, взнос и срок. Клиенту уйдёт ссылка, её можно и скопировать.
  4. Следите за этапами и оплатами в списке сделок. Оплату переводом или наличными отмечайте в карточке сделки.

Сейчас работает тестовый режим

SMS, проверка паспорта и оплата пока имитируются: деньги не списываются, SMS не отправляются. Для настоящей работы нужно подключить:

  • оплату: Т-Касса или другой эквайринг (ключи вписываются в settings.env);
  • SMS: например, SMSC.ru;
  • распознавание паспорта и сверку лица: например, Smart Engines;
  • проверку текста договора и соглашения о простой электронной подписи юристом.
