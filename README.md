# Сделка онлайн

Приложение для удалённых сделок: клиент проходит проверку личности, подписывает договор кодом из SMS, платит первоначальный взнос и дальше видит договор и график платежей в личном кабинете. Менеджер создаёт сделки и видит, на каком этапе каждый клиент.

Одна кодовая база для iPhone, Android и браузера (Expo SDK 57, React Native, Expo Router).

## Что уже работает

Клиент: приглашение → подтверждение телефона по SMS → фото паспорта и селфи, автозаполнение данных → договор с графиком → подпись простой электронной подписью → оплата взноса (СБП или карта) → личный кабинет (график, договор, история платежей, оплата следующего платежа).

Менеджер: список сделок со статусами, создание сделки (сумма, взнос, срок), карточка сделки с договором и графиком.

## Сервер

Папка `server/`: Node.js 22.18+, Fastify, база SQLite (встроенная в Node). Сервер хранит сделки, платежи и журнал всех действий клиента (кто, когда подтвердил телефон, подписал договор, оплатил), проверяет порядок этапов и ограничивает число попыток ввода кода.

```bash
cd server
npm install
npm start         # http://localhost:3000, при первом запуске создаёт демо-сделки
npm test          # автотесты всего пути сделки
```

Настройки через переменные окружения: `PORT`, `DB_FILE` (файл базы, по умолчанию `sdelka.db`), `SEED=off` (без демо-сделок), `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME` (первый менеджер, создаётся при первом запуске; по умолчанию `manager@demo.ru` / `demo1234`).

Менеджеры входят по почте и паролю (пароли хранятся в виде хеша scrypt, после 5 неверных попыток вход блокируется на 15 минут). Договор скачивается в PDF: `/api/client/<код приглашения>/contract.pdf`, после подписания в нём указаны подписант, время и идентификатор подписи.

## Приложение

```bash
npm install
npm run web       # в браузере, сервер должен быть запущен
npm start         # QR-код для приложения Expo Go на телефоне
```

Адрес сервера задаётся `EXPO_PUBLIC_API_URL` (по умолчанию `http://localhost:3000`; телефону нужен адрес компьютера в сети, например `http://192.168.1.10:3000`). Клиент открывает свою сделку по ссылке `/client?t=<код приглашения>`; без кода открывается демо-сделка.

## Тестовый режим

Внешние сервисы имитируются в `server/src/providers.ts`: SMS не отправляются (код везде `1234`), деньги не списываются, паспорт не распознаётся по-настоящему (подставляется пример).

Что осталось до работы с реальными клиентами:
1. SMS-шлюз для кодов.
2. Сервис распознавания паспорта и сверки лица (KYC).
3. Платёжный провайдер с СБП и картами.
4. Оператор электронной подписи, если простой подписи по SMS недостаточно; договор в PDF.
5. Размещение сервера (хостинг с хранением данных в России по 152-ФЗ).

Сборка для App Store и Google Play: `npx eas-cli@latest build` (нужен аккаунт Expo, Apple Developer и Google Play Console).

## Структура

- `src/app/` — экраны (каждый файл — отдельный экран): `client/*` для клиента, `manager/*` для менеджера
- `src/api.ts` — обращения к серверу
- `src/state/` — модель сделки и загрузка данных
- `server/` — сервер: `src/deals.ts` правила сделки, `src/app.ts` адреса API, `src/providers.ts` внешние сервисы
- `src/lib/` — расчёт графика платежей, форматирование сумм и дат
- `src/ui/` — общие компоненты, договор и таблица графика
